# ⚽ SOBRE O PROJETO

O **Whinsdor Club Site** é uma recriação digital e histórica de um dos clubes mais emblemáticos do futebol britânico fictício. Desenvolvido para reunir a história, o elenco e as conquistas, o projeto mostra a trajetória de um time renascido das cinzas — um símbolo de união, juventude e comunidade.

Inspirado no documento *“Whinsdor Club: Renascença de uma Lenda Perdida”*, o site apresenta a ascensão do clube desde sua fundação em **1863**, passando pela reconstrução em **2021** por quatro jovens visionários (*Eddie Spencer, Maggie Thorne, Ollie Darwin e Charlie Tudor*), até as grandes glórias modernas na Premier League e Champions League.

---

# 🚀 DESAFIOS E SUPERAÇÕES

O maior desafio no desenvolvimento deste projeto foi traduzir o peso de uma identidade histórica e tradicional de um clube de futebol em uma interface web moderna, fluida e responsiva utilizando a stack nativa (Vanilla):

| Desafio | Tecnologia Aliada | Como a tecnologia ajudou |
| :--- | :--- | :--- |
| **Identidade Visual Marcante** | **CSS Semântico & Variáveis** | Criação de uma paleta baseada no Azul-marinho (`#0B1B50`) e Amarelo-ouro (`#FFD700`), garantindo o contraste ideal e a atmosfera clássica dos clubes ingleses. |
| **Navegação Multipáginas Fluida** | **JavaScript (DOM & Events)** | Implementação de transições suaves e gerenciamento dinâmico de estados para alternar entre as sessões de História, Elenco e Conquistas sem quebras visuais. |
| **Exibição da Linha do Tempo** | **HTML5 & CSS Grid/Flexbox** | Estruturação de uma linha do tempo cronológica responsiva, permitindo que a trajetória de 1863 a 2034 seja lida perfeitamente em computadores ou celulares. |
| **Organização do Hall de Ídolos** | **CSS Cards & Hover Effects** | Desenvolvimento de uma galeria interativa para os grandes nomes como *Leonardo García* e *Angus MacLeod*, com efeitos de foco que destacam as lendas do clube. |
